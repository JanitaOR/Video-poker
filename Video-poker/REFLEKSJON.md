## Teknologivalg

React - jeg lager kompnenter som gjør det enklere å sette sammen appen på en mer ryddig måte.
TypeScript - lager typer for å spesifisere hvilke type de forskjellige propertisene i forskjellige elementer. gjør det lettere å unngå feil.
Zustand - gir tilgang til alle tilstander som trengs i flere kompnenter.
React Router - for å kunne lage navigasjon med enklere urler.
CSS - styling
Zustand persist - denne legger alt i localstorage så det er mulig å navigere seg mellom sider uten å miste tilstandene i spillet.
Git/Github - versjonskontroll
